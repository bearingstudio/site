Design Concept · 2026 · Hardware & Software ·

The Concept

You shouldn't need the internet to communicate with your car.

Beacon is a permissionless keyfob that eliminates the third-party server dependency built into modern connected vehicles. Instead of routing commands via a mobile app through a manufacturer’s cloud infrastructure, Beacon communicates directly with the vehicle over local Ultra Wideband and LoRaWAN protocols.

The Problem

Remote interaction is a feature until it isn't.

Today's cloud-dependent vehicle control ties functionality to corporate survival. When a manufacturer discontinues a connected service or simply goes bankrupt, these remote features customers paid for and expect are disabled, even with functional in-vehicle hardware. Beacon proposes that autonomy should remain in peoples' hands.

Specifications

Communication UWB + Class C LoRaWAN module
Range Primarily-local, long-range capable
Power supply Thermally stable sodium ion (Na-ion) battery, user serviceable
Dependencies None, LR relies on existing LoRaWAN network
Form factor Puck, 40mm diameter, recycled plastic chassis
Cybersecurity UWB utilizes Time-of-Flight (ToF) tracking for added security
Charging In-vehicle wireless charging and USB-C port

Context

Beacon is a design concept developed in conjunction with Cayenne: Design Empathy in the Digital Age, Bearing Studio's inaugural publication, which includes exclusive artwork of the device on page 57.
